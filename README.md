# Ahmed Raza Bhutto Mobile Shop Website

A modern, fully responsive website for **Ahmed Raza Bhutto Mobile Shop**.

## Features

- Attractive homepage / hero section
- Product catalog with filters (Samsung, Xiaomi, Infinix, Tecno, iPhone)
- Realistic Pakistani mobile prices
- Online Order form (Name, Phone, City, Model, Address, Notes)
- Facilities: Online Order, Best Prices, Genuine Products, Repair, Accessories, Easy Payment
- About the Owner – Ahmed Raza Bhutto
- Contact section
- Footer with owner name
- Clean modern design (teal/green primary + orange accent)
- Fully mobile-friendly

## How to View

Open `index.html` in any modern web browser.

## Files

- `index.html` – Main structure
- `styles.css` – All styling
- `script.js` – Products, filters, form logic
